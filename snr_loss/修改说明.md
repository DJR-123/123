# Event-guided HDR Reconstruction with Diffusion Prior

Yixin Yang, Jiawei Zhang, Yang Zhang, Yunxuan Wei, Dongqing Zou, Jimmy Ren, and Boxin Shi.

## News

**[April 2026]** Integrated **Hybrid Encoder** combining ConvLSTM (local details) + Swin Transformer V2 (global semantics) for enhanced HDR reconstruction quality.

## Requirements

- Python 3.10
- CUDA-compatible GPU
- timm (for Swin Transformer components)

## Usage

### Training

#### Single GPU Training

**Main Model Training (Stage 1)**

```bash
python train.py \
    --name "experiment_name" \
    --config "config/Train_hybrid.yaml"
```

**Upsampler Training (Stage 2)**

First, run inference sampling results without refinement (change the dataroot in config file to match the training data):
```bash
python up_test.py \
    --name "test_experiment" \
    --config "config/up_Test_hybrid.yaml" \
    --pretrained_unet "path/to/trained/model.ckpt" \
    --save
```

Then, start training based on the saved latents (change the dataroot in config file to match the saved latents):
```bash
python train_upsampler.py \
    --name "upsampler_experiment" \
    --config "config/Train_upsampler_hybrid.yaml" \
    --pretrained_unet "path/to/trained/model.ckpt"
```

#### Multi-GPU Training (DDP)

This project supports Distributed Data Parallel (DDP) for multi-GPU training and testing. DDP maintains the same training results while significantly accelerating the process.

**Two-Stage Training Workflow (Recommended)**

**Stage 1: Main Model Training**
```bash
# Main model training with 2 GPUs
torchrun --nproc_per_node=2 train.py \
    --name "experiment_name" \
    --config "config/Train_hybrid.yaml"
```

**Prepare for Stage 2: Generate Intermediate Results**
```bash
# Generate initial HDR results and save latents
python up_test.py \
    --name "test_experiment" \
    --config "config/up_Test_hybrid.yaml" \
    --pretrained_unet "path/to/stage1/model.ckpt" \
    --save

# Then modify config/Train_upsampler_hybrid.yaml:
# train_dataset.dataroot: "results/test_experiment/inputs_w_latents.h5"
```

**Stage 2: Upsampler Training**
```bash
# Upsampler training with 4 GPUs
torchrun --nproc_per_node=4 train_upsampler.py \
    --name "upsampler_experiment" \
    --config "config/Train_upsampler_hybrid.yaml" \
    --pretrained_unet "path/to/stage1/model.ckpt"
```

**Single Node Multi-GPU Training (Full Pipeline)**

**Multi-Node Multi-GPU Training**

```bash
# On node 0 (master node)
torchrun --nnodes=2 --nproc_per_node=4 \
    --node_rank=0 --master_addr="10.0.0.1" --master_port=29500 \
    train.py --name "experiment_name" --config "config/Train_hybrid.yaml"

# On node 1
torchrun --nnodes=2 --nproc_per_node=4 \
    --node_rank=1 --master_addr="10.0.0.1" --master_port=29500 \
    train.py --name "experiment_name" --config "config/Train_hybrid.yaml"
```

**DDP Notes**:
- Total batch size = `batch_size` × `num_gpus`, each GPU uses the same batch size as single GPU
- **Learning rate is linearly scaled**: effective lr = `config.learning_rate` × `num_gpus` (to maintain training consistency)
- **Training epochs aligned**: optimizer steps per GPU = `config.max_train_steps` / `num_gpus`, so epochs remain same as single GPU
- Model synchronization is handled automatically by DDP
- Only rank 0 (main process) handles logging, checkpoint saving, and validation
- Training results remain consistent with single GPU training

## Configuration

- `output_dir`: Output directory
- `pretrained_model_path`: Path to pre-trained Stable Diffusion model
- `pretrained_controlnet_model_path`: Path to pre-trained ControlNet model
- `encoder_type`: Encoder architecture type ('hybrid')
- `conditioning_channels`: Conditioning channel configuration
- `learning_rate`: Learning rate
- `batch_size`: Batch size
- `max_train_steps`: Maximum training steps

```yaml

encoder_config:
```

- `patch_size`: Image patch size

## Model Architecture

### Hybrid Encoder Architecture

**HDRev_Encoder_Hybrid** combines the strengths of both ConvLSTM and Swin Transformer:

- **Local Branch (ConvLSTM)**: Retains spatial details from HDRev pretrained weights
- **Global Branch (Swin Transformer V2)**: Captures global semantics from ImageNet-22K pretrained weights
- **Adaptive Fusion**: Dynamically blends local and global features
- **Parameters**: ~260M (ConvLSTM ~50M + Swin ~207M + Fusion)

**Architecture Design**:
```
HDRev_Encoder_Hybrid
├─ Local Branch (ConvLSTM) - Detail preservation
│  ├─ local_encoder_I (Image)
│  └─ local_encoder_E (Event)
│
├─ Global Branch (Swin V2) - Semantic understanding
│  ├─ global_encoder_I (Image)
│  └─ global_encoder_E (Event)
│
├─ AdaptiveFusion x 4 - Dynamic feature fusion
│
└─ FusionLayer_Unet - Final Image+Event fusion
```

### OursControlNetModel
ControlNet-based conditional control model supporting multiple input types:
- Event data (evs)
- Low dynamic range images (ldr)
- Event + low dynamic range images (evs+ldr)
- Multi-scale conditioning: [64, 128, 256, 512] channels

### OursAutoencoderKL
Improved autoencoder for image upsampling and detail enhancement. Used in Stage 2 training to refine HDR quality.

## Data Format

The project supports HDF5 format datasets containing:
- Event data (pixel_events)
- Low dynamic range images (pixel_images)
- High dynamic range images (target_images)

## Training Strategy

### Two-Stage Training Pipeline

**Stage 1: Base HDR Reconstruction**
- Train ControlNet + Hybrid Encoder
- Learn basic HDR reconstruction from events + LDR
- Output: Initial HDR results (~30k training steps)

**Stage 2: Detail Enhancement**
- Train Upsampler (VAE fusion layer)
- Refine details and improve resolution
- Input: Stage 1 results + VAE latents
- Output: High-quality HDR (~20k training steps)

### Training Time Estimation

| Stage | Steps | Single GPU | Dual GPU |
|-------|-------|------------|----------|
| Stage 1 | 30k | ~8-12h | ~4-6h |
| up_test | dataset size | ~1h | ~0.5h |
| Stage 2 | 15k | ~2-3h | ~1-1.5h |
| **Total** | - | **~11-16h** | **~5.5-8h** |

### Training Tips

**Learning Rate Strategy**:
```yaml
learning_rate: 0.00001  # Start with small learning rate

# Recommended:
# 1. First 10k steps: Freeze ConvLSTM and Swin, train fusion layers only
# 2. 10k-30k steps: Unfreeze fusion modules and upper features
# 3. 30k+ steps: Full model fine-tuning
```

**Memory Optimization**:
```yaml
# If GPU memory is insufficient:
batch_size: 1              # Reduce batch size
gradient_checkpointing: True  # Enable gradient checkpointing (~50% memory saving)
gradient_accumulation_steps: 2  # Equivalent to batch=2
```

### Performance Comparison

| Encoder | Detail Preservation | Global Consistency | Parameters |
|---------|---------------------|--------------------|------------|
| ConvLSTM | Excellent | Good | ~50M |
| Swin | Poor | Excellent | ~207M |
| **Hybrid** | **Excellent** | **Excellent** | **~260M** |

**Hybrid Encoder Benefits**:
- Retains spatial details from ConvLSTM branch
- Captures global semantics from Swin branch
- Leverages dual pretrained weights (HDRev + ImageNet-22K)
- Best quality for HDR reconstruction

## Troubleshooting

### CUDA Memory Issues
```yaml
# Solutions:
# 1. Reduce batch_size
batch_size: 1

# 2. Enable gradient_checkpointing
gradient_checkpointing: True

# 3. Reduce input resolution
patch_size: [256, 256]
```

### Pretrained Weights Not Found
```bash
# Check file paths:
ls pretrained/HDRev/
ls pretrained/SwinTransformer/

# Required files:
# - Encoder_I.pth, Encoder_E.pth, Merge.pth (HDRev)
# - swinv2_base_patch4_window12_192_22k.pth (Swin)
```

### Upsampler Training Errors
```bash
# 1. Ensure up_test.py ran successfully:
python up_test.py --name hybrid_up_test --config config/up_Test_hybrid.yaml \
    --pretrained_unet checkpoints/stage1/model.ckpt --save

# 2. Check latents file exists:
ls results/hybrid_up_test/inputs_w_latents.h5

# 3. Update Train_upsampler_hybrid.yaml:
# train_dataset.dataroot: "results/hybrid_up_test/inputs_w_latents.h5"
```
